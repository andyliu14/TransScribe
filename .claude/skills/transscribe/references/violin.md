# Violin

Open strings sound G3, D4, A4 and E5. Write treble clef at concert pitch. An exposed phrase on the D string can retain a darker color above the open A if the player shifts. Specify a string only when that color matters.

Check a bowed slur against the crossings and dynamic it asks for. At a triple-stop accent, decide which pitch sustains after the chord rolls. For a repeated figure, trace the bow direction at the repeat as well as the first entrance. Try the pitches on adjacent strings before promising a simultaneous double stop.
